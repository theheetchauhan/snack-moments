1

System context

The Question Lab is a standalone engine. It designs the study; an app builder turns the design into the apps; live data flows back so the engine improves.

2

One engine run

From a brief to a validated, playable game. A proven live design is reused; anything new is drafted, redesigned, debated and piloted.

3

Design ⇄ critique loop

A writer model designs, plain-code rules repair, a critic from a different model family scores. Repeat until the bias risk is low.

4

LLM gateway

One gateway for every AI call: cached, routed by role, schema-checked, metered, and backed by a rule-based fallback.

5

Data & learning loop

Player events become quality scores and dashboards; weak questions are rewritten from evidence and return to the next study.
